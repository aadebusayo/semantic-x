# Contributing to SemanticX

Thanks for wanting to contribute! This document provides a short checklist and guidelines to make contributions easy to review.

## How to contribute

- Fork the repository and create a feature branch for your work.
- Open a pull request against `main` with a clear title and description.
- If your change is code, include tests for new behavior and run the test suite locally.

## Code style

- Follow existing style in the repository. We use Black for formatting.
- Keep changes small and focused (one logical change per PR).

## PR checklist

- [ ] The PR has a descriptive title and description
- [ ] Tests added or updated for new behavior
- [ ] Lint/format checks pass (Black)
- [ ] Documentation updated where applicable

## Reporting bugs

- Open an issue with a short reproduction and expected behavior.

## Code of conduct

Be respectful and constructive. If you'd like a formal code of conduct added, open an issue.

Thanks — maintainers
